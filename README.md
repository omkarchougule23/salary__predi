# Salary Prediction using Machine Learning

## Project Overview

This project predicts the salary of an employee based on their years of experience using Machine Learning.

## Dataset

The project uses the Salary Prediction dataset from Kaggle.

## Machine Learning Model

Linear Regression

## Input

- Years of Experience

## Output

- Predicted Salary

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit

## Project Structure

Salary_Prediction/
- data/
- model/
- screenshots/
- train_model.py
- app.py
- requirements.txt
- README.md

## Model Evaluation

The model is evaluated using:

- MAE
- MSE
- RMSE
- R² Score
